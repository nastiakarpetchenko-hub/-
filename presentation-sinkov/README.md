# Презентация SINKOV — «Реализованные объекты»

Материалы презентации портфолио для сайта и новых клиентов.

| Файл | Что это |
|---|---|
| `sinkov-deck.html` | Вёрстка презентации. Открывается в браузере двойным щелчком |
| `logo.png` | Фирменный знак |
| `ТЗ-для-Cowork.md` | Задание на наполнение фотографиями: карта подстановки всех кадров |
| `photos/` | Папки под фотографии объектов, по одной на объект |

## Что делать дальше

1. Разложить фотографии по папкам внутри `photos/` и переименовать по описаниям
   из раздела 4 техзадания.
2. Подставить их в `sinkov-deck.html` по карте оттуда же.
3. Удалить строку-плашку `<p class="draft">…</p>` — это пометка черновика.
