# content/

- `plan.yaml` — твой контент-план (создаётся из `plan.example.yaml`).
- `media/` — видео и фотографии, на которые ссылается план.
- `.state.json` — журнал: что и куда уже опубликовано. **Не удаляй** —
  именно он не даёт опубликовать один и тот же пост дважды.

`plan.yaml`, `media/*` и `.state.json` не попадают в git (см. `.gitignore`):
контент и журнал публикаций живут рядом с рабочим сервисом, а не в репозитории.
