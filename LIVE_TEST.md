# Живой тест бота в облачной сессии

Как запустить бота прямо в Claude Code на вебе (без Railway) для проверки.

## Предусловия (настраиваются в среде ДО старта сессии)
1. **Сеть среды:** `Full` (или `Custom` с доменами `api.telegram.org` и
   `huggingface.co`, галочка «Also include default list…» включена).
2. **Переменная окружения** среды (в том же диалоге):
   ```
   BOT_TOKEN=<токен от @BotFather>
   WHISPER_MODEL=small
   ```
   (`small` — чтобы тест шёл быстрее; потом можно `medium`).

> ⚠️ Изменения сети/переменных применяются к **новым** сессиям, а не к уже
> запущенной. После правки среды нужно **создать новую сессию** на этом же
> репозитории и ветке `claude/skill-setup-dependencies-jg6eu0`.

## Что сделать ассистенту в новой сессии
```bash
npm install          # если зависимости ещё не стоят
npm run bot          # запуск бота (long polling)
```
Дождаться в логах строки:
```
✓ Бот @имя_бота на связи
```
Затем пользователь шлёт боту в Telegram **короткое видео до 20 МБ**
(лимит Telegram Bot API на скачивание). Бот вернёт ролик с субтитрами.

## Ограничения теста
- Только видео **< 20 МБ** (ограничение Bot API, снимается self-hosted Bot API).
- Среда **эфемерная** — засыпает без активности. Для 24/7 нужен постоянный хостинг.
- После теста пересоздай токен через @BotFather (`/token`) — он «светился».
